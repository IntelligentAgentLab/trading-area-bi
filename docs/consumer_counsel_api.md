## 5. 데이터 한계 (분석 전 꼭 확인)

1. **자유 텍스트 없음** — 위 3번 항목 참고. `dscsnCnClNm`은 고정 카테고리이지 원문이 아님.
2. **표본 편향** — 이 데이터는 "상담·불만이 접수된 건"만 모은 것이라, 실제 소비 규모나 만족도와는 무관하게
   특정 업종·채널에 민원이 몰려 보일 수 있음. 매출 등 다른 데이터와 교차 검증 없이 "이 업종이 문제가 많다"고
   해석하면 안 됨.
3. **결측치** — 필드별로 0.3~3% 수준 존재 (`exploration/consumer_counsel_app.py`에서는 "미상"으로 채워서 처리).
4. **세부 지역(`areaCd`/`areaCdNm`)은 235종으로 노이즈가 많음** — "울릉군", "여천군" 같은 옛 행정구역명이나
   "오세아니아", "남아메리카" 같은 해외 권역이 섞여 있어, 지역 분석은 `upAreaNm`(18종) 기준을 권장.
5. **접수기관(`instNm`)이 146개** — 한국소비자원 본원 외에 지역 소비자단체·지자체가 다수 포함되어 있어,
   기관별 분석보다는 접수 채널(`rcptMthCdNm`) 기준이 더 유용함.
