# 빅카인즈 수동 다운로드 안내

Open API가 유료라 이 폴더는 **수동으로 bigkinds.or.kr에서 검색 → 엑셀 다운로드**한 파일을 넣는 곳입니다.

## 업종 구분을 하지 않는 이유

전에는 업종별로 4번 검색해서 각각 파일로 받고, 대시보드에서도 업종별로 토픽을 나눠 보여줬습니다.
그런데 생각해보면 "외식업 매출이 급증한 시기의 원인 뉴스"를 찾을 때 그 뉴스에 "식당"·"카페" 같은
업종 키워드가 꼭 들어있어야 할 이유가 없습니다(예: "긴급재난지원금 지급" 뉴스는 업종명이 없어도
외식업 매출에 영향을 줌). 그래서 이제는 **업종 구분 없이, 분기별로 소상공인 전반의 이슈만** 봅니다.
대시보드에서 업종을 선택해도 뉴스 토픽 패널은 바뀌지 않고 "이 분기 전체 동향"을 그대로 보여줍니다.

## 검색 방법

1. [bigkinds.or.kr](https://www.bigkinds.or.kr) 회원가입 → 로그인
2. **뉴스 검색·분석** 메뉴 진입
3. 검색어: `소상공인 OR 자영업` (하나로 묶어서 한 번에 검색 — 상세검색의 OR 연산자나 검색창에
   직접 `OR` 타이핑 둘 다 가능)
4. 기간은 다른 데이터와 맞추는 걸 권장합니다 — 1372 소비자상담 데이터는 2022-01~2026-07입니다.
   결과가 20,000건 근처로 너무 많으면 기간을 나눠서 여러 번 받아도 됩니다(중복은 스크립트가
   "뉴스 식별자" 기준으로 자동 제거).
5. 검색 결과 화면에서 **엑셀 다운로드**
6. 받은 파일을 이 폴더에 저장 — **파일명은 자유**입니다(업종 구분을 안 하므로 파일명이 의미를
   갖지 않음). 여러 번 나눠 받았으면 전부 이 폴더에 넣으면 됩니다.
